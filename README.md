# Zuma's Revenge! Vita
A PlayStation Vita port of Zuma's Revenge!
Not affiliated with PopCap, EA or Sony.

This is currently a beta build. (v0.46)
The source code will be updated on launch.

## Installation Prerequisites
- A Vita with HENkaku and [kubridge](https://github.com/bythos14/kubridge) installed, and `libshacccg.suprx`
  (needed by vitaGL's runtime shader compiler).
- The game's data files in `ux0:data/zuma/` on the Vita (`assets/`).

## Installation Instructions
- Download ZumasRevenge.vpk from the releases page.
- Download zuma-assets.zip from the releases page.
- Install the VPK using VitaShell.
- Copy the zuma-assets.zip to your PS Vita using a FTP or USB transfer into 'ux0:data/'
- Extract zuma-assets.zip. The resulting folder paths should be 'ux0:data/zuma/assets/etc.'
- Have fun! The game will play at 60 fps without overclocking.

Please contact me on Reddit if you experience glitches!
Access to additional crash dumps also helps bugfix.
